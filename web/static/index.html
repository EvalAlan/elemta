Off by default, and measured: draining the same 12,000-message queue gave 137/s with this off and 87/s with it on. Keeping the copy costs roughly a third of delivery throughput, on every delivery. Turn it on only if you may roll this server back to a build older than the content-digest change (2026-08-08): an older build reads that copy, and without it would treat a re-sent message as a conflict and refuse it.
