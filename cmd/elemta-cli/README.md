# elemta-cli

`elemta-cli` is currently a lightweight helper binary.

## Build

```bash
make build
```

Binary:

- `bin/elemta-cli`

## Current commands

```bash
bin/elemta-cli status
bin/elemta-cli queue
```

## Notes

For full queue management and operational commands, use:

- `bin/elemta queue ...`
- HTTP API endpoints exposed by `bin/elemta web`
